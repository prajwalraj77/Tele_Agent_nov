# Voice Agent Dashboard

Simple React dashboard for the existing Node.js backend.

## Start

```bash
npm install
npm run dev
```

The app runs on Vite's default port `5173` and calls the backend at:

`http://localhost:5000`

## Main files

- `src/App.jsx` - dashboard UI and table
- `src/services/api.js` - backend API calls
- `src/styles.css` - dashboard styling
